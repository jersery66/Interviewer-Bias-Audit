# 实验设计—文献依据映射表

## 1. 文档目的与使用边界

本文档回答“为什么要做这项分析、它与既有研究是什么关系、结果最多能说明什么”。它是现有实验的方法学证据包，不是新实验计划，也不是事后把每个参数包装成“文献规定”。本表依据正式锁定的研究文件、运行清单和已核验的出版物整理；不改变任何模型、结果、统计检验或论文结论。

本研究的中心问题不是比较哪个单一输入的 AUC 最高，而是审计不同输入来源的预测信息及其条件独立性：

1. 不同来源分别具有多大的预测充分性；
2. 访谈者侧文本在患者语言、数量与互动结构、协议路径及患者症状代理进入模型后，是否仍有条件增量；
3. 真实参与者—访谈者配对是否保留结构匹配无法解释的额外排序信息，以及患者症状代理是否特异性解释该增量。

## 2. 记号与证据强度

### 2.1 本研究记号

- `P`：在单来源和条件增量分析中指参与者语言表示；在访谈者分数可恢复性模块中，特指严格交叉拟合的参与者侧模型 logit。
- `I`：访谈者语言表示或其严格交叉拟合模型分数，具体含义随分析目标注明。
- `Q`：文本数量与互动分布，包括双方词数、话轮数、访谈时长及每话轮平均词数。
- `R`：协议路径与覆盖。条件增量模型使用冻结的 5 个协议计数；可恢复性模块还使用冻结规则导出的提示位置、密度、转移、路径深度以及提示 ID 的计数/存在变量。
- `D-P`：只从参与者语言中提取的 10 域症状代理，不是完整访谈症状变量、独立临床量表或临床诊断。

### 2.2 证据强度分级

- **A级：直接先例**——既有论文在 DAIC-WOZ 上直接操作了相同来源、视角或症状层级。
- **B级：概念或操作类比**——既有论文支持研究该层面的必要性，但没有使用本研究完全相同的变量或对照。
- **C级：本研究扩展**——没有找到等同的发表实验；分析是从前述问题自然延伸出的识别或负对照设计。
- **D级：内部质量控制**——目的在于验证本研究构造、统计或证据链，不对应外部论文的效果复现。

“有文献依据”不等于“本研究复现了该文全部模型”，也不等于“文献证明了本研究的结果”。

## 4. “复现已有问题”与“本研究扩展”的正式分层

### 4.1 复现或验证既有问题

本研究前半部分验证四类已有问题在同一冻结队列和统一评估框架中的表现：

1. 参与者回答与访谈者提示可以分开建模；
2. 提示类别、提示区域及协议上下文可能影响预测；
3. patient/therapist 或 question/answer 的视角与话语结构不应被完整转录掩盖；
4. 症状层级表示可以作为总标签之外的中间层，但需要临床或人工证据检验。

这些分析的作用是建立研究起点，不构成本研究最强的新颖性主张。

### 4.2 本研究的主要扩展

本研究的核心扩展是把上述通常分开研究的来源放入同一条件增量框架：比较 `P+Q+R+D-P` 与 `P+Q+R+D-P+I`，并把“单独可预测”与“控制后仍有独立增量”严格区分。

### 4.3 识别与负对照扩展

- Real−Random 检查真实配对相对完全随机错配的差异；
- Real−Matched 进一步控制可观测的文本量和协议结构；
- Real D-P 增量−Fake-D 增量检验“真实症状内容特异吸收 I”的狭义解释。

这些对照提高替代解释的可检验性，但仍是观察性、模型依赖的识别敏感性分析。

## 5. 可直接用于论文的三个研究问题

- **RQ1：来源充分性。** 参与者语言、访谈者语言、非显性访谈者语言和参与者症状证据在统一划分与表示下分别具有多大的队列内预测充分性？
- **RQ2：条件增量。** 访谈者语言在参与者语言、数量与互动结构、协议路径和参与者症状代理进入模型后，是否仍具有稳定的条件增量？
- **RQ3：配对与症状特异性。** 真实参与者—访谈者配对是否包含结构匹配无法解释的额外排序信息，以及真实 `D-P` 是否比标签盲 Fake-D 更能解释访谈者增量的变化？

## 6. 师兄追问时的简短回答

### 为什么不只比较 P 和 I 的 AUC？

因为单来源 AUC 只回答“这个来源单独够不够预测”，不能回答它在其他来源已知后是否还有新增信息。论文主问题是条件增量，不是单来源排行榜。

### 为什么要有 Q、R、D-P 三类控制？

它们对应三种不同替代解释：文本量与互动分布、脚本化协议路径、患者症状内容。把三者混在完整转录里，无法判断 I 的信息究竟与哪一层重叠。

### 为什么 Real−Random 还不够？

随机错配会同时破坏真实对应和词量/协议结构相似性。Matched 保留这些可观测结构的接近程度，因此是更严格的对照；但它仍不能消除所有未测混杂。

### 为什么一定要做 Fake-D？

只有真实 D-P 降低 I 增量并不足以证明症状内容的特异作用。Fake-D 保留同样的维度和建模位置，但破坏患者—症状对应，用于检验该解释是否超出一般特征竞争或标签对齐。

### 为什么做多种表示而不是继续找更强模型？

目的是检查结论是否由 TF-IDF 或某个 dense encoder 决定。模型均在运行前冻结并全部报告；本研究不按 AUC 选择“最佳模型”。

### 为什么 D-P 可以用，但不能叫临床金标准？

D-P 来自参与者语言，并在抽样域级单元上完成双人盲审和人工共识比较，因此可作为经验证的代理变量；但它不是独立临床访谈或完整症状真值，也没有对全部参与者逐域建立人工金标准。

## 9. 证据包结论

现有实验不是若干互不相关的追加分析，而是一条递进证据链：

> 单来源充分性 → 条件增量 → 访谈者分数可恢复性 → 随机与结构匹配配对破坏 → Fake-D 症状特异性负对照 → 人工效度与来源忠实性验证。

既有文献直接支持“来源、提示、话语结构和症状层面值得分别研究”；本研究的贡献是把这些层面放入统一的条件增量与识别敏感性框架。最稳妥的结论是对 DAIC-WOZ 中预测信号来源进行方法学审计，而不是把模型性能等同于患者症状识别、访谈者因果偏倚或临床有效性。
