# 复现指南

## 冻结范围

- 队列：官方 train+dev，共 142 人（阳性 43 人，阴性 99 人）。
- 结局定义：PHQ-8 ≥ 10。
- 共享划分：`00_splits/repeated_5fold_splits_10x5.csv`，即 10 次重复 × 5 折。
- 参与者层面推断：先对每人 10 个重复 OOF 概率取均值，再执行 10,000 次参与者层面的配对随机交换。
- 多重比较：在 4 个冻结的检验族内分别进行 BH-FDR 校正。
- 官方 test 不进入主分析。

## 运行环境

- Python：3.12.8
- 平台：Windows-11-10.0.26200-SP0
- NumPy：2.3.3
- pandas：2.3.3
- matplotlib：3.10.7
- 主运行清单保存了精确的 scikit-learn 版本、模型 revision、随机种子、计算设备、池化方式、缓存哈希和运行时间。

## 执行命令

在隔离 worktree 根目录中激活已记录的虚拟环境，然后依次运行：

```powershell
python scripts/prepare_analysis_v2.py
python scripts/run_tfidf_main.py
python scripts/run_embedding_model.py --model mpnet
python scripts/run_embedding_model.py --model bge
python scripts/finalize_embedding_analysis.py
python scripts/run_c5_controls.py
python scripts/run_c4_controls.py
python scripts/build_final_package.py
python -m pytest -q
```

模型命令可通过 `--help` 查看显式的输出与模型参数。实际完成运行所使用的精确 revision 保存在各模型目录的 `run_manifest.json` 中。Embedding 缓存采用内容寻址，并被纳入 SHA-256 清单。

## 完整性验证

- `integrity_audit.csv`：验证已有的全部 SHA-256 产物清单。
- `strict_contract_audit.csv`：验证主输入及 C4 控制输入哈希、train/dev 范围、C4 话轮输入与 C3/C4 的 142/142 一致性、划分成员及无重叠、参与者层面 OOF 数量、检验族规模、10,000 次置换、C5 quote 排除与词数匹配，以及 C4 词数匹配。
