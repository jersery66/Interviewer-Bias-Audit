# C5 证据卡人工验证材料说明

## 工作流变更

本方案取代旧有的全转录十领域重新编码流程。人工复核对象改为从锁定来源表中平衡抽取的证据卡，不再要求评分者重新通读全部访谈并重建十领域结果。

## 正式任务范围

每位评分者 120 张正式证据卡，每个锁定领域 12 张。评分者只判断证据有效性、所属领域和证据极性；备注仅用于必要说明，不构成额外的必填判断。

本方案不评估缺失证据，也不计算召回率。它仅检查已抽取证据的内容有效性、领域归属和极性，不应被表述为对完整访谈证据覆盖率的验证。

## 受限材料边界

包含证据引文、上下文、评分者中间表、负责人交叉表和正式发放材料的受限评分材料不纳入 Git。仓库仅保留公开说明、生成代码和不含真实受限内容的合成测试。

## 当前状态

当前状态是材料准备，尚未完成人工验证。不得声称已经完成评分、评分者间一致性、分歧处理、共识形成或任何人工效度结论。
