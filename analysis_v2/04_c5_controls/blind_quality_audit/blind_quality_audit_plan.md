# D-P blind manual quality audit contract

**Lock date:** 2026-07-14  
**Status:** post-audit content-validity check; not preregistered  
**Scope:** the frozen participant-derived D-P domain counts only

## Sampling

- Frame: the same official 142 participants used by the frozen D-P input.
- Sample size: 30 participants.
- Stratification: paper label (0/1) × participant-speech word-count tertile (short/middle/long), with five participants per cell.
- Sampling seed: `20260714`.
- The label and word-count fields are used only for owner-side sampling and are excluded from the reviewer packet.

## Reviewer blinding

Each reviewer receives only the participant-language text for the 30 blinded case IDs. The packet excludes participant IDs, PHQ-8 scores, binary labels, model outputs, existing D-P counts, interviewer language, and sampling strata. Reviewers work independently and do not see the other reviewer's file.

For each case and each of the ten frozen domains, the reviewer records:

1. binary presence (`0` absent / `1` present);
2. an exact evidence quote copied from the participant text;
3. an uncertainty note when the evidence is ambiguous.

The ten domains and their frozen column names are: `anhedonia_interest`, `appetite_weight`, `concentration_psychomotor`, `depressed_mood`, `functioning_impairment`, `mental_health_history`, `protective_or_absent_symptom`, `self_worth_guilt`, `sleep_fatigue_energy`, and `suicide_self_harm`.

## Agreement and scoring

When two completed reviewer files exist, report domain-level agreement rate and Cohen's kappa. Disagreements require an explicit adjudication/consensus value before computing D-P-versus-consensus precision, recall, and F1; no consensus is inferred from one reviewer's choice.

If only one reviewer is available, report only the blinded single-reviewer content-validity sample. Do not report Cohen's kappa, inter-rater agreement, or a fabricated consensus comparison.

## Owner-only files

The owner retains a separate sample key and D-P scoring reference containing participant IDs, labels, word counts, and existing D-P counts. These files must not be supplied to reviewers. The generated packet is a preparation artifact; no reviewer judgments are generated by code.
