# 新研究论文框架与摘要草稿

## 推荐题目

面向可解释抑郁识别的临床访谈文本输入策略研究：访谈者偏差与患者症状证据比较

## 备选题目

1. 临床访谈文本中访谈者话语偏差对大语言模型抑郁识别的影响：基于 DAIC-WOZ 的复现与扩展研究
2. 基于临床访谈文本的大语言模型抑郁识别效度研究：访谈者话语偏差与患者症状证据分析
3. 面向临床辅助评估的抑郁识别输入策略研究：完整对话、访谈者偏差与患者症状证据的比较

## 中文摘要草稿

目的：探讨临床访谈文本中不同输入来源对大语言模型抑郁识别效度的影响，重点分析访谈者话语偏差和患者症状证据输入的可解释性价值。

方法：本研究基于 DAIC-WOZ 临床访谈数据集，以 PHQ-8 总分是否达到 10 分作为抑郁阳性标签，构建完整对话、仅患者回答、仅访谈者提问、清洗后访谈者提问和患者症状证据五种输入条件。研究首先使用 TF-IDF 结合 Logistic Regression 和 Linear SVM 建立传统文本分类基线，随后使用大语言模型进行零样本抑郁二分类。分类性能采用 Accuracy、F1、Macro-F1、AUC、MCC、Sensitivity 和 Specificity 评价；输入偏差采用 Interviewer Bias Performance Gap 和 Diagnostic Prompt Dependency 指标评估；同时对大语言模型输出的 evidence 进行来源和有效性分析。

结果：本研究将比较不同输入条件下模型识别性能，重点检验仅访谈者提问条件是否具有异常预测能力，以及删除诊断性访谈问题后性能是否下降。进一步分析完整对话输入中模型解释是否依赖访谈者问题，并评估患者症状证据输入是否在保持可接受识别性能的同时提高证据有效性。

结论：临床访谈抑郁识别模型可能受到访谈者话语偏差影响。相比直接输入完整对话，患者症状证据输入更有助于减少证据来源混淆，提高模型判断依据的临床可解释性和复核价值。

关键词：抑郁识别；临床访谈；大语言模型；可解释性；访谈者偏差；DAIC-WOZ

## English Abstract Draft

Objective: This study aims to examine how different sources of clinical interview text influence the validity of depression detection with large language models, with a particular focus on interviewer speech bias and the interpretability value of patient symptom evidence.

Methods: Using the DAIC-WOZ clinical interview dataset, clinically significant depressive symptoms will be defined by a PHQ-8 score of 10 or above. Five input conditions will be constructed: full dialogue, participant-only responses, interviewer-only prompts, interviewer prompts after diagnostic-question cleaning, and participant symptom evidence only. Traditional text classification baselines will be built with TF-IDF features and Logistic Regression or Linear SVM, followed by zero-shot large language model classification. Model performance will be evaluated using Accuracy, F1, Macro-F1, AUC, MCC, Sensitivity, and Specificity. Input bias will be assessed using Interviewer Bias Performance Gap and Diagnostic Prompt Dependency. In addition, evidence returned by large language models will be analyzed by source and clinical validity.

Expected Results: The study will compare model performance across input conditions, test whether interviewer-only prompts show abnormal predictive performance, and examine whether performance decreases after removing diagnostic interviewer prompts. It will further evaluate whether full-dialogue inputs lead models to rely on interviewer questions in their explanations and whether symptom-evidence inputs improve evidence validity while maintaining acceptable classification performance.

Conclusion: Depression detection models based on clinical interviews may be affected by interviewer speech bias. Compared with direct full-dialogue input, patient symptom evidence may provide a more clinically interpretable and auditable input strategy.

Keywords: depression detection; clinical interview; large language model; interpretability; interviewer bias; DAIC-WOZ

## 论文结构

### 1. Introduction

第一段：抑郁自动识别的意义。强调抑郁筛查、临床辅助评估、访谈文本自动分析的现实价值。

第二段：临床访谈文本是重要数据来源，但输入方式会影响模型效度。完整对话虽然信息丰富，却混合了患者表达与访谈者提问。

第三段：既有研究提示访谈者 prompts 可能带来数据捷径或偏差，但主要集中于传统模型或特定建模方式。LLM 是否存在类似问题，以及其解释证据是否混入访谈者问题，仍需验证。

第四段：本研究提出基于 DAIC-WOZ 的复现与扩展，比较五种输入条件，并同时评估分类性能与证据来源，以提出更适合临床辅助评估的输入策略。

### 2. Methods

2.1 Dataset

- DAIC-WOZ 数据来源、访谈形式、样本划分。
- PHQ-8 >= 10 的二分类标签规则。
- 纳入排除标准：有 transcript、有 PHQ-8 标签、有 split 信息。

2.2 Input Construction

- C1 Full dialogue
- C2 Participant-only
- C3 Interviewer-only
- C4 Interviewer-cleaned
- C5 Symptom evidence-only

2.3 Diagnostic Prompt Cleaning

- 关键词规则。
- 诊断性问题定义。
- 清洗前后 Ellie 提问数统计。

2.4 Symptom Evidence Extraction

- LLM 抽取 prompt。
- 症状类别。
- JSON 输出规范。
- 人工抽样核查。

2.5 Models

- TF-IDF + Logistic Regression
- TF-IDF + Linear SVM
- GPT-4o-mini
- Qwen2.5-72B-Instruct

2.6 Evaluation Metrics

- 分类性能：Accuracy、Precision、Recall、F1、Macro-F1、AUC、MCC、Specificity、Sensitivity。
- 偏差指标：IBPG、DPD。
- 解释指标：EVR、IER。

2.7 Statistical Analysis

- 描述性统计。
- 成对条件 McNemar test。
- Bootstrap 95% CI。
- 可选混合效应 logistic 回归。

2.8 Evidence Annotation

- 抽样 30 个样本。
- 两名标注者。
- 标注字段和 Cohen's Kappa。

### 3. Results

3.1 Sample Characteristics

报告抑郁组与非抑郁组在 PHQ-8、访谈轮次、患者词数、Ellie 提问数、诊断性问题数上的差异。

3.2 Performance Comparison Across Input Sources

展示模型 × 输入条件性能表，重点比较 Full、Participant-only、Interviewer-only。

3.3 Effect of Removing Diagnostic Interviewer Prompts

报告 Interviewer-only 到 Interviewer-cleaned 的性能变化和 DPD。

3.4 LLM Evidence Source Analysis

报告 EVR、IER、无效证据比例，展示 Full dialogue 是否出现较多访谈者证据。

3.5 Error Analysis and Representative Cases

展示 2-3 个典型案例：访谈者问题导致误判、患者症状证据纠正误判、完整对话证据混淆。

### 4. Discussion

4.1 Interviewer prompts may inflate depression detection performance

解释访谈者问题中的结构性线索如何成为模型捷径。

4.2 LLMs are not immune to dataset shortcuts

说明 LLM 的自然语言理解能力并不自动保证临床效度。

4.3 Patient symptom evidence provides a more clinically valid input

强调 Evidence-only 的可复核性、证据集中性和临床解释价值。

4.4 Implications for HAMD-17 and clinical interview-based assessment

把本研究与后续 HAMD-17 访谈文本输入策略连接起来：不是简单把整段访谈塞给模型，而是先构造症状证据层。

4.5 Limitations

- DAIC-WOZ 不是 HAMD-17 数据。
- PHQ-8 标签只是二分类近似。
- Evidence extraction 本身可能受 LLM 影响。
- 诊断性问题清洗规则仍需人工复核。
- LLM 结果可能受模型版本影响。
