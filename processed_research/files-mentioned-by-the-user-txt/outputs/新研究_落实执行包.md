## 一句话版本

这篇文章的主线不是单纯复现既有 DAIC-WOZ 研究，而是检验一个更适合你主课题的临床方法学问题：

> 在大语言模型进行临床访谈抑郁识别时，完整对话输入是否会让模型依赖访谈者话语偏差？患者症状证据输入能否在保持识别性能的同时提高判断证据的临床有效性和可复核性？

推荐题目：

**面向可解释抑郁识别的临床访谈文本输入策略研究：访谈者偏差与患者症状证据比较**

## 核心研究问题

RQ1. LLM 是否受到访谈者话语偏差影响？

- 比较：Full dialogue、Participant-only、Interviewer-only
- 关键判断：如果 Interviewer-only 也有较高 F1 或 MCC，说明模型可能利用访谈者问题线索完成识别。

RQ2. 删除诊断性访谈者问题后，预测性能是否下降？

- 比较：Interviewer-only、Interviewer-cleaned
- 关键判断：如果 Interviewer-cleaned 明显下降，说明偏差主要来自情绪、睡眠、自杀、治疗史等诊断性提问。

RQ3. 患者症状证据输入是否更临床合理？

- 比较：Participant-only、Symptom evidence-only
- 关键判断：如果 Evidence-only 性能接近 Participant-only，同时文本更短、证据更集中、EVR 更高，则可作为更可复核的临床辅助输入策略。

RQ4. LLM 的解释证据来自哪里？

- 分析 evidence 中的 speaker 与 evidence_type
- 关键判断：如果 Full dialogue 条件下 IER 较高，说明完整对话输入可能造成解释证据来源混淆。

## 可检验假设

H1. Interviewer-only 条件的分类性能显著高于随机水平，并可能接近 Participant-only。

H2. Interviewer-cleaned 相比 Interviewer-only 的性能下降，说明诊断性访谈者问题提供了捷径线索。

H3. Evidence-only 的 Macro-F1/MCC 接近 Participant-only，但 Evidence Validity Ratio 高于 Full dialogue。

H4. Full dialogue 条件下，LLM 输出证据中会出现一定比例的 interviewer_prompt 证据，提示解释偏差。

## 数据与标签

数据集：DAIC-WOZ 临床访谈转录文本。

标签：

- PHQ-8 >= 10：depressed = 1
- PHQ-8 < 10：depressed = 0

推荐划分策略：

- 优先使用 DAIC-WOZ 原始 train/dev/test 划分。
- 如果 test 标签不可得：传统模型用 train 训练、dev 测试；LLM 零样本直接在 dev 上评估。
- 如果需要更稳定估计：在 train + dev 上做 5-fold stratified cross-validation，并在论文中明确说明。

## 五种输入条件

| 条件 | 名称 | 内容 | 目的 |
|---|---|---|---|
| C1 | Full dialogue | Ellie + Participant 全部对话 | 模拟常见完整对话输入 |
| C2 | Participant-only | 只保留患者回答 | 检验患者语言本身的预测力 |
| C3 | Interviewer-only | 只保留 Ellie 提问 | 检验访谈者话语偏差 |
| C4 | Interviewer-cleaned | 删除诊断性问题后的 Ellie 提问 | 判断偏差是否来自诊断性提问 |
| C5 | Symptom evidence-only | 从患者回答中抽取症状证据 | 检验证据化输入是否更临床合理 |

## 诊断性访谈问题清洗规则

先用关键词规则实现可复现版本，再在论文中说明这是 operational definition。

建议删除包含以下主题的 Ellie 问题：

| 类型 | 英文关键词示例 |
|---|---|
| 情绪 | depressed, sad, down, hopeless, unhappy |
| 兴趣 | interest, pleasure, enjoy |
| 睡眠/疲劳 | sleep, insomnia, tired, fatigue, energy |
| 食欲 | appetite, eating, weight |
| 自杀/自伤 | suicide, suicidal, kill yourself, hurt yourself, self-harm |
| 精神健康史 | mental health, therapy, counselor, treatment |
| 药物 | medication, antidepressant |
| 创伤 | trauma, abuse, ptsd |
| 诊断 | diagnosed, depression, anxiety |

保留普通流程性问题，例如：

- can you tell me more?
- what happened next?
- how long ago was that?
- where are you from?

## 模型方案

最小可执行版本：

| 模型类型 | 模型 | 用途 |
|---|---|---|
| 传统基线 | TF-IDF + Logistic Regression | 稳定、可解释、易复现 |
| 传统基线 | TF-IDF + Linear SVM | 文本分类强基线 |
| LLM 零样本 | GPT-4o-mini | 闭源强基线，成本较低 |
| LLM 零样本 | Qwen2.5-72B-Instruct | 国产/本地大模型对照 |

扩展版本可加入 DeepSeek-V3/R1、Qwen2.5-7B/14B、Random Forest、XGBoost。

## 评价指标

分类性能：

- Accuracy
- Precision
- Recall / Sensitivity
- Specificity
- F1
- Macro-F1
- AUC
- MCC

主指标：

- Macro-F1
- MCC

偏差与解释指标：

- IBPG = F1(Interviewer-only) - F1(Participant-only)
- DPD = F1(Interviewer-only) - F1(Interviewer-cleaned)
- EVR = 有效患者症状证据数 / 全部证据数
- IER = 访谈者问题证据数 / 全部证据数

## 人工标注方案

抽样：

- 30 个样本
- 每个样本 4 个输入条件的 LLM 输出
- 总计约 120 条解释结果
- 两名标注者独立标注

字段：

- 是否有效
- 是否来自患者
- 是否为症状证据
- 是否为访谈者诱导性问题
- 是否支持模型判断

一致性：

- Cohen's Kappa
- 证据有效率
- 访谈者偏差证据率
- 症状证据命中率

## 直接开工顺序

1. 准备 Python 环境。依赖见 `新研究_requirements.txt`。
2. 准备 DAIC-WOZ transcript 文件、PHQ-8 标签文件、split 文件。
3. 运行 `新研究_实验代码骨架.py` 生成五种输入条件。
4. 先跑传统模型：LR 和 Linear SVM，确认 C3/C4 是否出现预期差异。
5. 用 `新研究_LLM提示词与输出规范.md` 批量跑 LLM 零样本分类。
6. 把 LLM 输出 evidence 展开成长表，抽 30 个样本填 `新研究_人工标注模板.csv`。
7. 汇总分类指标、IBPG、DPD、EVR、IER。
8. 按 `新研究_论文框架与摘要.md` 写 Methods 和 Results。

安装依赖示例：

python -m pip install -r outputs\新研究_requirements.txt
