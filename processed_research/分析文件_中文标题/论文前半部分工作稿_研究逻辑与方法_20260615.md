# 临床访谈文本输入条件对抑郁识别模型的影响：基于 DAIC-WOZ 的访谈者话语偏差分析

> 工作稿用途：本稿用于固定当前研究逻辑、方法路线和变量定义。结果与讨论部分后续可继续接在本文件之后。当前版本基于已完成的 C1-C4 输入条件、TF-IDF + Logistic Regression、TF-IDF + Linear SVM、all-mpnet-base-v2 + Logistic Regression、偏差指标、阈值敏感性分析和 McNemar 检验。C5 symptom evidence-only 与 API 型大语言模型实验尚未纳入当前主分析。

## 摘要草稿

临床访谈文本已被广泛用于自动化抑郁识别，但完整访谈文本并不只包含受访者自身的症状表达，也包含访谈者的提问、追问和诊断性提示。若模型在完整对话输入下表现较好，其性能可能部分来自访谈者话语中的结构性线索，而非完全来自患者自身的抑郁症状证据。这一问题会影响模型性能解释、临床可解释性以及真实场景中的外部效度。

本研究基于 DAIC-WOZ 数据集，构建四类文本输入条件：完整对话（C1）、仅受访者话语（C2）、仅访谈者话语（C3）以及删除诊断性问题后的访谈者话语（C4）。研究以 PHQ-8 总分构建抑郁二分类标签，并在 189 名有标签参与者上评估不同输入条件对模型表现的影响。模型方面，本研究首先建立传统文本分类基线，包括 TF-IDF + Logistic Regression 和 TF-IDF + Linear SVM，并进一步使用 all-mpnet-base-v2 句向量结合 Logistic Regression 作为语义表征基线。评价指标包括 Accuracy、F1、Macro-F1、AUC 和 MCC。为了量化访谈者话语偏差，本研究定义 Interviewer Bias Performance Gap（IBPG）和 Diagnostic Prompt Dependence（DPD），分别衡量仅访谈者话语相对仅受访者话语的性能差异，以及删除诊断性问题后访谈者话语性能的变化。

本研究的核心目标不是追求最高分类性能，而是检验不同输入来源对抑郁识别模型的贡献和潜在偏差。该设计有助于区分模型是否真正利用患者自身表达，还是依赖访谈流程、诊断性提问和访谈者话语所提供的间接线索。后续研究可在当前 C1-C4 框架基础上扩展 C5 症状证据输入条件，并在完成额外实验后进一步比较 API 型大语言模型在分类与证据解释中的偏差来源。

## 1 引言

基于语音、文本和多模态行为数据的心理健康自动识别近年来受到持续关注。与量表或结构化问卷相比，临床访谈文本包含更丰富的自然语言表达，能够反映个体对情绪、睡眠、兴趣、功能损害、人际关系和生活事件的叙述。因此，使用访谈转录文本进行抑郁识别不仅具有建模价值，也具有潜在的临床辅助评估意义。

然而，临床访谈文本并不是单纯的患者自述。以 DAIC-WOZ 这类半结构化访谈数据为例，一段完整对话同时包含受访者回答和访谈者提问。访谈者的提问通常具有明确的访谈流程和临床目标，其中一部分问题直接涉及抑郁、焦虑、创伤、睡眠、兴趣、自杀意念或治疗经历等心理健康主题。如果模型直接使用完整对话进行训练和测试，模型可能学习到的不仅是患者的症状表达，也可能是访谈者针对不同受访者提出的问题类型、问题密度和诊断性话语模式。

这种现象在方法学上形成一个重要问题：完整对话输入下较高的预测性能，是否一定意味着模型捕捉到了患者自身的抑郁症状证据？如果仅使用访谈者话语也能获得较高分类性能，则说明模型可能利用了访谈者提问中的结构性线索。进一步地，如果删除诊断性问题后，仅访谈者话语的预测性能明显下降，则说明访谈者话语的预测力可能主要来自心理健康相关的诊断性提问，而不是一般访谈结构。这会对既有模型评估产生影响：模型看似能够从临床访谈中识别抑郁，实则可能部分依赖数据采集流程中已经隐含的临床判断或访谈引导。

这一问题对于所有临床访谈文本模型都很重要。无论模型使用词项特征、语义嵌入还是更强的上下文表征，较高预测性能本身都不能自动保证其证据来源是临床上合理的。若完整对话中包含明显的访谈者提示，模型可能将问题本身视为预测线索，或者在解释中引用访谈者问题而非患者回答。对于临床辅助系统而言，这种输入来源依赖会降低解释可靠性，也会限制模型在不同访谈风格、不同机构和不同临床流程中的泛化能力。

因此，本研究将抑郁识别问题从“模型能否预测正确”进一步推进到“模型依赖哪一类文本线索”。本文基于 DAIC-WOZ 数据集构建多种输入条件，并比较传统文本分类模型和语义表征模型在不同输入来源下的表现。通过将完整对话、患者话语、访谈者话语和清洗后的访谈者话语进行系统对比，本研究希望回答：抑郁识别模型是否会从访谈者话语中获得额外预测信息？这种信息是否主要来自诊断性提问？仅患者话语是否存在阈值或类别不平衡导致的性能低估？这些问题共同构成本文的方法学核心。

本研究的贡献主要包括三点。第一，本文将访谈者话语偏差作为临床访谈文本抑郁识别中的显式研究对象，而不是将访谈者文本简单视为上下文噪声或完整输入的一部分。第二，本文构建 C1-C4 四类输入条件，分别对应完整对话、患者话语、访谈者话语和删除诊断性问题后的访谈者话语，从而能够分解不同文本来源对模型性能的贡献。第三，本文提出 IBPG 和 DPD 两个偏差指标，并结合 Macro-F1、MCC、阈值敏感性分析和 McNemar 配对检验，使模型比较不只停留在单一 F1 或 Accuracy 上。

## 2 研究问题

本文当前阶段聚焦于 C1-C4 输入条件，研究问题如下。

RQ1：访谈者话语是否具有独立的抑郁预测能力？  
该问题通过比较 C2 participant-only 与 C3 interviewer-only 的模型性能来回答。如果 C3 的 Macro-F1 或 MCC 明显高于 C2，则说明模型在不接触患者回答的情况下，仍能从访谈者话语中获得预测线索。

RQ2：访谈者话语的预测能力是否依赖诊断性问题？  
该问题通过比较 C3 interviewer-only 与 C4 interviewer-cleaned 来回答。C4 删除了访谈者话语中与抑郁、焦虑、创伤、睡眠、治疗、自杀意念等主题直接相关的诊断性问题。如果 C4 相比 C3 性能下降，则说明访谈者话语的预测力可能主要来自诊断性提问；如果 C4 仍保持较高性能，则说明一般访谈流程、追问模式或对话结构本身也可能携带与标签相关的信息。

RQ3：完整对话输入的性能是否掩盖了患者话语与访谈者话语的贡献差异？  
该问题通过比较 C1 full dialogue、C2 participant-only 和 C3 interviewer-only 来回答。如果 C1 表现较好，但 C2 表现较弱而 C3 表现较强，则需要谨慎解释完整对话模型的性能来源。

RQ4：类别不平衡和默认阈值是否影响对 participant-only 条件的判断？  
DAIC-WOZ 当前样本中抑郁阳性比例较低，因此默认分类阈值可能导致模型倾向预测阴性。本文通过 Macro-F1、MCC、AUC 和阈值敏感性分析共同判断 C2 的低 F1 是否完全意味着患者话语无效，还是部分反映阈值选择和类别不平衡问题。

## 3 方法

### 3.1 数据来源与样本

本研究使用 DAIC-WOZ 数据集中的临床访谈转录文本。DAIC-WOZ 由虚拟访谈者 Ellie 与参与者进行半结构化访谈，常用于抑郁、心理困扰和多模态心理健康识别研究。当前分析仅使用有标签且可获得转录文本的 train 和 dev 样本，不使用无标签 test 集。

当前纳入样本共 189 名参与者，其中 PHQ-8 < 10 的阴性样本为 147 名，PHQ-8 >= 10 的阳性样本为 42 名。原始划分中 train 集 143 名，dev 集 46 名；train 集包含 111 名阴性和 32 名阳性，dev 集包含 36 名阴性和 10 名阳性。样本平均年龄为 38.99 岁，标准差为 12.44；男性 102 名，女性 87 名。PHQ-8 总分均值为 6.75，标准差为 5.92。

需要强调的是，本研究使用 PHQ-8 构建二分类标签，但研究目的不是重新估计 PHQ-8 分数，也不是替代临床诊断。本文关注的是：在相同标签下，不同文本输入条件会如何改变模型表现，以及这种改变是否揭示了访谈者话语偏差。

### 3.2 标签定义

抑郁二分类标签依据 PHQ-8 总分生成：

- PHQ-8 >= 10：depressed = 1，表示具有临床显著抑郁症状；
- PHQ-8 < 10：depressed = 0，表示未达到临床显著抑郁症状阈值。

该阈值是 DAIC-WOZ 相关研究中常用的二分类标准。由于阳性样本占比约为 22.2%，数据存在类别不平衡。因此，本文所有 Logistic Regression 和 Linear SVM 分类器均使用 `class_weight="balanced"`，并在评价中加入 Macro-F1 和 MCC，以减少 Accuracy 在类别不平衡场景下的误导。

### 3.3 输入条件构建

本研究的关键设计是将同一名参与者的访谈文本拆分为不同输入条件。当前主分析包含 C1-C4 四类输入，每类均对应同一批参与者，因此模型差异可以解释为输入来源差异，而不是样本来源差异。

C1 Full dialogue：完整对话输入。  
该条件保留访谈者 Ellie 和参与者的全部转录文本，用于模拟常见的完整访谈文本输入方式。C1 包含 189 行非空文本，平均词数为 2266.71，标准差为 866.61。

C2 Participant-only：仅患者话语输入。  
该条件只保留参与者回答，删除访谈者提问。它用于检验患者自身语言表达是否足以支持抑郁识别。C2 包含 189 行非空文本，平均词数为 1471.19，标准差为 811.39。

C3 Interviewer-only：仅访谈者话语输入。  
该条件只保留访谈者 Ellie 的提问和话语，删除患者回答。它是本文检验访谈者话语偏差的关键条件。如果模型在 C3 上仍能预测抑郁标签，则说明访谈者话语本身携带与标签相关的线索。C3 共 189 行，其中 186 行为非空文本，3 行为空文本；平均词数为 544.88，标准差为 113.27。

C4 Interviewer-cleaned：删除诊断性问题后的访谈者话语输入。  
该条件在 C3 基础上删除访谈者话语中的诊断性或心理健康主题问题，例如直接涉及 depressed、sad、hopeless、interest、sleep、appetite、suicide、therapy、medication、trauma、PTSD、depression、anxiety 等主题的问题。其目的不是完全消除所有访谈结构信息，而是尽量去除显性诊断提示，从而检验 C3 的预测能力是否依赖这些高诊断性问题。C4 共 189 行，其中 186 行为非空文本，3 行为空文本；平均词数为 438.49，标准差为 91.20。相较 C3，C4 平均删除 7.32 个诊断性访谈者轮次。

为提高 C4 的可审计性，本文补充整理了清洗规则目录、逐参与者清洗摘要和人工审阅模板。article-aligned 清洗规则共覆盖 depressed mood、anhedonia/interest、sleep/fatigue/energy、appetite/weight、self-worth/guilt、concentration/psychomotor、suicide/self-harm 和 mental-health history 等八类问题。该规则从 186 名具有访谈者话语的参与者中共删除 1,384 个访谈者轮次，保留 13,615 个访谈者轮次；平均每名参与者删除 7.32 个轮次。附录 A 列出完整规则和审计路径，人工审阅模板保留空白 `human_review_decision` 与 `reviewer_notes` 字段，用于后续人工标记正确删除、误删、漏删或不确定案例。

当前文件名中使用 `conditions_long__RECOMMENDED_article-aligned_analysis-ready_C1-C4_no-C5.csv` 作为主分析输入表。该文件采用长表结构，每名参与者对应四行输入条件，共 756 行。C5 symptom evidence-only 暂未纳入当前主分析，因为该条件需要进一步通过规则或大语言模型从患者话语中抽取症状证据，并进行人工或半自动质量控制。

### 3.4 文本预处理与质量控制

所有输入条件均保留转录文本的基本语言内容，并对空文本进行显式标记。对于 C3 和 C4，部分样本没有可用访谈者话语，因此在模型训练和交叉验证时默认删除空文本行。当前质量标记显示，451、458 和 480 三个样本没有 interviewer turns，因此在 C3/C4 的建模中会被排除。

为了避免不同输入条件之间混淆，本文不将 C1-C4 合并训练，而是对每一种输入条件分别训练和评估模型。也就是说，C1 模型只看完整对话，C2 模型只看患者话语，C3 模型只看访谈者话语，C4 模型只看清洗后的访谈者话语。这样的设计可以将性能差异解释为输入条件差异，而不是模型同时接触多类输入后产生的混合效应。

### 3.5 模型设置

本研究当前阶段使用三类基线模型。

第一类为 TF-IDF + Logistic Regression。文本首先通过 TF-IDF 向量化，设置为 lowercase=True、strip_accents="unicode"、ngram_range=(1, 2)、min_df=2、max_features=50000、sublinear_tf=True。分类器为 Logistic Regression，solver="liblinear"，max_iter=2000，class_weight="balanced"，random_state=42。

第二类为 TF-IDF + Linear SVM。其 TF-IDF 设置与 Logistic Regression 相同，分类器为 LinearSVC，max_iter=10000，class_weight="balanced"，random_state=42。Linear SVM 作为传统文本分类中的强基线，用于检验 LR 结果是否依赖特定线性分类器。

第三类为 all-mpnet-base-v2 + Logistic Regression。该条件使用 sentence-transformers/all-mpnet-base-v2 将文本编码为句向量，并进行 L2 归一化。随后使用 Logistic Regression 进行二分类，分类器仍使用 class_weight="balanced"。该模型不是 API 型生成式大语言模型，而是语义表征基线，用于观察预训练语义嵌入是否会改变 C1-C4 输入条件之间的关系。

当前研究尚未将 GPT、Qwen、DeepSeek 等 API 型大语言模型作为主结果纳入。后续若加入 LLM，应将其定位为扩展实验：在相同 C1-C5 输入条件下，使用统一 prompt 进行零样本或少样本分类，并额外分析模型解释中引用的证据来源。

### 3.6 评估策略

本文采用两种评估方式。第一种为固定 train/dev 评估，即使用 DAIC-WOZ 原始 train 划分训练模型，并在 dev 划分上测试。这一方式贴近数据集原始设定，但 dev 样本量较小，结果可能受划分影响。第二种为 5-fold stratified cross-validation，即在当前 189 名有标签样本上进行分层五折交叉验证，并报告每个模型和输入条件的平均性能与标准差。当前论文主表优先使用 5-fold CV 结果，固定 train/dev 结果作为补充与 McNemar 配对检验来源。

评价指标包括 Accuracy、Precision、Recall、F1、Macro-F1、AUC 和 Matthews correlation coefficient（MCC）。其中，F1 关注阳性类别识别能力；Macro-F1 同时考虑阴性和阳性类别，在类别不平衡时比 Accuracy 更稳定；MCC 综合考虑 TP、TN、FP 和 FN，在不平衡二分类中具有较好的诊断价值；AUC 则用于评估模型排序能力，尤其帮助判断低 F1 是否来自阈值问题。

### 3.7 偏差指标定义

为量化访谈者话语偏差，本文定义两个核心指标。

第一，Interviewer Bias Performance Gap（IBPG）：

IBPG = Performance(interviewer_only) - Performance(participant_only)

该指标衡量仅访谈者话语相对于仅患者话语的性能差异。若 IBPG 为正，说明访谈者话语在该指标上比患者话语具有更高预测性能，提示模型可能利用访谈者问题中的偏差信号。本文分别基于 F1、Macro-F1 和 MCC 计算 IBPG。

第二，Diagnostic Prompt Dependence（DPD）：

DPD = Performance(interviewer_only) - Performance(interviewer_cleaned)

该指标衡量删除诊断性访谈者问题后，访谈者话语预测性能的变化。若 DPD 为正，说明 C3 的一部分预测能力来自被删除的诊断性问题；若 DPD 接近 0 或为负，则说明访谈者话语中的预测线索并不完全依赖显性诊断问题，也可能来自一般访谈流程、追问方式或其他结构性因素。本文同样基于 F1、Macro-F1 和 MCC 计算 DPD。

### 3.8 阈值敏感性与上界分析

由于数据存在明显类别不平衡，默认分类阈值可能导致模型倾向预测阴性，尤其影响 participant-only 条件下的阳性 F1。因此，本文增加阈值敏感性分析，用于判断低 F1 是否部分由阈值选择导致。

阈值敏感性分析仅针对 TF-IDF + LR 和 TF-IDF + SVM 进行。首先，本文保留默认 5-fold CV 结果作为主分析结果。其次，为避免直接在测试折上选择阈值造成信息泄漏，本文进行 nested threshold 分析：在每一个外层测试折中，仅使用外层训练数据进行内层交叉验证，生成训练数据的 out-of-fold 预测分数，并在这些分数上搜索使 MCC 最大的阈值；随后用完整外层训练折重新训练模型，并将该阈值应用于外层测试折。该结果用于评估在较严格、无测试标签参与的阈值选择流程下，participant-only 条件是否能够恢复阳性识别能力。

最后，本文报告 oracle threshold 作为乐观上界分析。oracle threshold 直接在外层测试折上搜索使 MCC 最大的阈值，因此不能作为实际可部署模型的性能估计，也不用于主要结论推断。它的作用是回答一个上界问题：如果允许使用测试标签选择最优阈值，某一输入条件的排序分数最多可以转化为多高的分类性能。nested threshold 与 oracle threshold 的对照有助于区分“模型完全没有可用信息”和“模型有排序信息但阈值不稳定”这两种情况。

### 3.9 McNemar 配对检验

为了检验不同输入条件在同一批 dev 样本上的预测差异，本文使用 McNemar 精确检验进行配对比较。该检验基于同一模型在两个输入条件下对同一参与者的预测正确与错误情况，重点关注两种条件之间的不一致预测数量。

当前 McNemar 检验基于固定 train/dev 预测结果，比较三组输入条件：C1 full dialogue vs C2 participant-only、C2 participant-only vs C3 interviewer-only、C3 interviewer-only vs C4 interviewer-cleaned。由于 dev 样本量较小，McNemar 检验在本文中主要作为补充统计证据，而不作为唯一结论来源。主要结论仍需结合 5-fold CV、IBPG/DPD、Macro-F1、MCC、AUC 和阈值敏感性分析共同判断。

## 4 结果部分工作稿

### 4.1 样本特征与输入文本长度

本研究共纳入 189 名 DAIC-WOZ 参与者，其中 PHQ-8 < 10 的阴性样本为 147 名，PHQ-8 >= 10 的阳性样本为 42 名，阳性率约为 22.2%。原始划分中 train 集包含 143 名参与者，dev 集包含 46 名参与者。train 集中阴性 111 名、阳性 32 名；dev 集中阴性 36 名、阳性 10 名。两组在 train/dev 划分上的比例基本一致。

四类输入条件均来自同一批参与者，因此不同条件之间的性能差异主要反映文本来源差异，而不是样本构成差异。完整对话 C1 的平均词数最高，为 2266.71；participant-only C2 的平均词数为 1471.19；interviewer-only C3 的平均词数为 544.88；删除诊断性问题后的 interviewer-cleaned C4 平均词数下降至 438.49。C3 和 C4 各有 3 个样本没有可用访谈者文本，建模时删除空文本行。C4 相比 C3 平均删除 7.32 个诊断性访谈者轮次，说明清洗步骤确实减少了心理健康主题相关提问。

### 4.2 模型输入条件的主结果

5-fold CV 结果显示，不同输入条件之间存在明显差异。对于 TF-IDF + Logistic Regression，participant-only 条件下阳性类 F1 为 0，Macro-F1 为 0.437，MCC 为 0；但 interviewer-only 条件下 F1 提高至 0.633，Macro-F1 为 0.746，MCC 为 0.515。TF-IDF + Linear SVM 呈现相似模式：participant-only 条件下 F1 和 MCC 均为 0，而 interviewer-only 条件下 F1 为 0.640，Macro-F1 为 0.766，MCC 为 0.534。

这一结果提示，在传统 TF-IDF 线性模型中，访谈者话语本身具有较强的抑郁标签预测能力。由于 interviewer-only 条件不包含任何患者回答，该结果不能解释为模型捕捉到了患者的直接症状表达，而更可能反映访谈者提问、访谈流程或诊断性提示中包含与标签相关的结构性线索。

MPNet 语义表征模型呈现出不同模式。MPNet + Logistic Regression 在 participant-only 条件下 Macro-F1 为 0.633，MCC 为 0.297；interviewer-only 条件下 Macro-F1 为 0.609，MCC 为 0.239。与 TF-IDF 模型相比，MPNet 对患者话语的利用能力更强，且没有表现出 interviewer-only 明显高于 participant-only 的模式。这说明访谈者偏差并不是所有表征方法中都以同样形式出现，但在传统词项特征模型中表现非常突出。

### 4.3 IBPG 与 DPD 偏差指标

为了进一步量化访谈者话语偏差，本文计算了 IBPG 和 DPD。5-fold CV 结果中，TF-IDF + Logistic Regression 的 IBPG 为：F1 = 0.633，Macro-F1 = 0.308，MCC = 0.515。TF-IDF + Linear SVM 的 IBPG 为：F1 = 0.640，Macro-F1 = 0.328，MCC = 0.534。两个传统模型均显示 interviewer-only 明显优于 participant-only，支持“访谈者话语携带预测性偏差信号”的判断。

DPD 的结果更为复杂。TF-IDF + Logistic Regression 的 DPD 为正，Macro-F1 = 0.096，MCC = 0.186，说明删除诊断性问题后，interviewer-cleaned 的性能低于 interviewer-only，提示诊断性问题解释了部分访谈者话语预测力。但 TF-IDF + Linear SVM 的 DPD 接近 0 或略为负值，Macro-F1 = -0.011，MCC = -0.028，说明删除显性诊断性问题后，SVM 的 interviewer-cleaned 表现并未下降。该结果提示，访谈者话语偏差可能不仅来自少数显性诊断问题，也可能来自更一般的访谈结构、追问模式或问题分布。

MPNet + Logistic Regression 的 IBPG 为负值或接近 0，说明语义表征模型并未复现 TF-IDF 模型中强烈的 interviewer-only 优势。这一差异提示，偏差来源可能与特征表征方式相关：TF-IDF 更容易利用访谈者问题中的词项线索，而语义嵌入模型可能更多捕捉患者回答中的整体语义信息。

### 4.4 阈值敏感性分析

由于 participant-only 条件下出现“AUC 中等但默认阈值下阳性类 F1 = 0”的现象，本文进一步进行了阈值敏感性分析。该分析的目的不是替代默认 5-fold CV 主结果，而是检验 participant-only 的低 F1 是否部分由阈值选择和类别不平衡造成。

Nested threshold 分析显示，participant-only 条件在更严格的内层交叉验证调阈值流程下可以恢复一定阳性识别能力。对于 TF-IDF + Logistic Regression，participant-only 的 F1 从默认阈值下的 0 提高到 0.423，Macro-F1 提高到 0.626，MCC 提高到 0.295；对于 TF-IDF + Linear SVM，participant-only 的 F1 为 0.424，Macro-F1 为 0.612，MCC 为 0.279。该结果说明，默认阈值确实压低了 participant-only 条件下的阳性类识别结果，因此不能简单将默认 F1 = 0 解释为患者话语完全没有预测信息。

不过，即使在 nested threshold 下，访谈者话语相关条件仍保持更高性能。TF-IDF + Logistic Regression 在 interviewer-only 和 interviewer-cleaned 条件下的 MCC 分别为 0.494 和 0.462，高于 participant-only 的 0.295；TF-IDF + Linear SVM 在 interviewer-only 和 interviewer-cleaned 条件下的 MCC 分别为 0.562 和 0.535，也高于 participant-only 的 0.279。这表明，阈值选择可以部分恢复患者话语的可用信息，但并不能消除 TF-IDF 线性模型中访谈者话语条件的性能优势。

Oracle threshold 进一步提供了乐观上界。若直接在测试折上选择最优阈值，participant-only 条件的 MCC 可达到 0.523（TF-IDF + LR）和 0.502（TF-IDF + SVM），说明患者话语分数中确实存在较强排序信息。然而，oracle threshold 使用测试标签选择阈值，不能作为实际模型性能估计。它的主要意义在于说明 participant-only 并非无信息输入，而是存在“排序能力可见、默认决策边界不稳定”的问题。

因此，本文对 participant-only 的解释需要收紧：默认阈值下 F1 = 0 并不代表患者话语没有预测信息；nested/oracle 分析均提示患者话语包含可用信号。但在无测试标签参与的 nested threshold 设置下，访谈者话语和清洗后访谈者话语仍表现出更高 MCC，说明 TF-IDF 线性模型更容易将访谈者侧线索转化为稳定分类决策。这一结果强化了本文的核心方法学警示：完整访谈输入的性能可能同时混合患者表达与访谈者互动线索，不能直接等同于患者症状证据的建模效果。

### 4.5 McNemar 配对检验

在固定 train/dev 集上进行的 McNemar 配对检验未发现不同输入条件间的预测差异具有统计学显著性，所有比较的精确 p 值均大于 0.05。具体而言，Full vs Participant、Participant vs Interviewer、Interviewer vs Cleaned 三组比较在 TF-IDF + Logistic Regression、TF-IDF + Linear SVM 和 MPNet + Logistic Regression 中均未达到显著水平。

该结果主要受限于 dev 集样本量较小和不一致样本数偏低。McNemar 检验的配对样本量为 44-46，不一致样本数仅为 1-13。在这种条件下，检验统计功效有限，p 值不显著并不必然否定 5-fold CV 中观察到的输入条件差异。因此，本文主要依据 5-fold 交叉验证结果、IBPG/DPD 偏差指标以及阈值敏感性分析进行结论推断，而将固定 train/dev 上的 McNemar 检验作为补充证据。

## 5 后续讨论写作提示

讨论部分应回到临床解释：完整访谈输入可能提高模型性能，但也可能引入访谈者问题、诊断性提示和访谈流程信息。对于临床辅助评估而言，模型是否预测正确并不是唯一问题；同样重要的是模型预测依据是否来自患者自身症状证据，还是来自访谈互动过程中形成的间接线索。

后续讨论可以重点展开四点。第一，TF-IDF 模型中 interviewer-only 明显优于默认阈值下的 participant-only，并且在 nested threshold 后仍保持更高 MCC，说明传统文本模型可能高度依赖访谈者问题中的词项和流程线索。第二，participant-only 在 nested/oracle threshold 下可以恢复一定性能，因此不能将默认 F1 = 0 解释为患者话语无效；更合理的解释是患者话语包含排序信息，但默认决策边界在类别不平衡条件下不稳定。第三，interviewer-cleaned 在部分模型中仍保持较高性能，提示偏差不一定只来自显性诊断性关键词，也可能来自访谈结构和追问分布。第四，MPNet 与 TF-IDF 的模式不同，说明更强的语义表征可能缓解但不能自动消除输入来源偏差。

讨论中还需要明确一个边界：interviewer-only 信号不一定是“坏偏差”或简单数据泄漏。DAIC-WOZ 的访谈者问题可能受到患者前序回答、访谈流程、访谈者根据患者回答进行的动态追问和系统追问策略共同影响，因此访谈者话语可以被理解为 interaction-derived signal，即由访谈互动过程产生的间接预测信号。它在预测上可能有用，但在解释上需要谨慎，因为它不能直接等同于患者自己的症状陈述。如果一个模型主要依赖这类信号，其临床解释应被表述为“利用了访谈过程中的互动线索”，而不是“识别了患者语言中的抑郁症状证据”。

未来更临床合理的方向是构建 C5 symptom evidence-only，使模型输入更接近“患者自身症状证据”，并进一步分析 LLM 解释是否真正引用患者话语而非访谈者问题。
